# BlockCraft 2.0

A simple Minecraft-inspired sandbox game built with HTML5 Canvas and JavaScript.

## Features

- Side-scrolling terrain generation
- Jumping and movement
- Block mining and building
- Inventory hotbar with 5 selectable blocks
- Day/night sky animation
- Basic resource gathering system

## How to play

- Move: A / D or Left / Right Arrow
- Jump: W / Up Arrow / Space
- Mine: Left click
- Place block: Right click
- Select block: 1 through 5

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

This is a lightweight browser game inspired by classic sandbox building games, designed to be easy to run and modify.
